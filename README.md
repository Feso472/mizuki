# Mizuki / 弥月

Early vanilla Repentance+ character prototype. REPENTOGON is deliberately not
used or required.

## Current prototype

- A separate playable character named `弥月`.
- Uses copied Isaac sprite and UI assets as temporary placeholders.
- Starts with Isaac-like basic stats, but with no starting collectible: no D6.

The selection-screen name image still says `ISAAC` until Mizuki's custom UI
art is added. The registered player name is already `弥月`.
